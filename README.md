StayScape 🏡

StayScape is an Airbnb-inspired full-stack web application where users can discover unique places to stay, create and manage property listings, save their favorite stays to a wishlist, and share ratings and reviews. It is built with Node.js, Express.js, MongoDB, EJS, Bootstrap, Cloudinary, and Mapbox to provide a simple and seamless booking-style experience.


## Features

* User authentication
* Create, edit, and delete listings
* Wishlist functionality
* Ratings and reviews
* Image uploads
* Interactive maps
* Responsive design

## Tech Stack

* Node.js
* Express.js
* MongoDB
* EJS
* Bootstrap
* Cloudinary
* Mapbox

## Run Locally

```bash
npm install
npm start
```
